Before every authorized spawn, read root AGENTS.md, VERIFY/squadbots/SKILL.md and this file. Installed skills do not grant spawn permission. Preserve model/role settings. Coordinator never edits product code; one writer per branch/worktree and one owner per PR.

Every initial and resumed brief includes GOAL, SCOPE, CONTEXT, ACCEPTANCE, VERIFY, TIMEBOX, FORBIDDEN, REPORT, STANDING. Ground each field; hold affected work when authority or evidence is missing.

Swarm workers receive identical acceptance rubric, exact head and base SHA, and disjoint owned output paths. Return PASS, ISSUES or BLOCKED, commands with exits, logs, actual model family, coverage and all proven findings. Missing workers and SHA mismatches block aggregate acceptance. Same-family or sequential review is coverage only, never independent ACCEPT.

A verdict pins one SHA. New head, base or candidate-byte changes void acceptance. Maker never self-approves or merges. Require fresh different-family ACCEPT, required green exact-head CI and user-path/regression evidence. Unknown model identity or missing proof is BLOCKED. Human review remains required; no remote action is authorized by this document.

Autopilot choice: autopilot-stack. Existing coupled uncommitted patches need coordinated review; human eyes precede any merge. Autopilot-full is not authorized. No Cursor plugin or plugin fetch is needed.
