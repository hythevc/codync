# Codync feature verification index

Grounded recipe map, not a PASS catalogue. Read [skill](../SKILL.md) and [harness](../../../docs/guide/06-harness.md). Every feature below is BLOCKED for complete end-to-end proof until actually driven on its required target. Computer-order has one live-tested logic regression; other recipes are source-grounded only. Native desktop macOS/Windows comes first, iPhone second, terminal later. Marketing website is outside the approved first-candidate scope.

Each file records entry points, subfeatures, drive steps, result proof, prerequisites and evidence. No selector or automation tool is claimed to exist. Feature pages link authoritative docs for platform-specific secondary entries; confirm code drift before driving. Preserve failures and record unrun paths.
